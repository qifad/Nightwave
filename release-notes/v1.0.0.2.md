## 更新系统

- 新增 GitHub Releases 联网检测，直接读取正式发布标题、版本号和更新说明。
- 发现新版本时弹出统一更新窗口，不再后台静默替换数据包。
- 更新窗口显示当前版本、目标版本、更新包体积和相对当前数据包的大小差。
- 更新说明按 Release Markdown 标题和条目分组显示，保留完整发布内容。
- 设置页的更新入口与启动时自动检测共用同一弹窗和下载流程。

## 稳定性修复

- 修复数据包下载中断后可能遗留不完整暂存目录的问题。
- 修复更新包文件校验失败时仍可能继续激活的问题。
- 修复旧的仓库文件更新方式无法显示 Release 更新日志的问题。
- 增加 Release ZIP 内容校验，只写入更新清单声明的文件。

## 测试说明

- 此版本为 `v1.0.0.2` Release 更新流程测试包。
- 数据包包含主播放器、扩展编辑器、打包工具和 FFmpeg 运行资源。
